# ADR-0002：使用 Ant Design X Bubble 统一消息展示外壳

## 状态

已采纳。

## 背景

聊天消息此前自行实现角色对齐、背景和圆角，同时由内容组件处理 Markdown、思考过程、
图表及动态表单。继续扩展自定义外壳会重复维护通用气泡能力，但直接迁移到
`Bubble.List` 又会牵动现有会话状态、流式更新和页面滚动策略。

## 决策

- 每条消息使用一个 Ant Design X `Bubble`，不引入 `Bubble.List`。
- `Bubble` 只负责角色对齐、气泡变体、主题色和底部操作区。
- 消息领域类型、流式 Markdown 和结构化内容仍由现有聊天 feature 解析与渲染。
- 用户消息使用主题主色填充；AI 消息使用无背景变体，成功后提供整条回答复制入口。

## 影响

消息外观统一复用公共组件，后续可继续使用 Bubble 的语义插槽。聊天协议、Store、
滚动逻辑和内容渲染器保持不变，降低迁移风险。
