# Tazhive 术语表

## 聊天响应协议

### 传输信封

后端用于同时承载回答正文与结构化数据的 JSON 对象。`content` 保存 Markdown 正文，
`charts` 保存图表定义。传输信封属于协议层数据，不应直接进入展示组件。

### 稳定解码前缀

流式 JSON 字符串中已经收到完整字符边界、可以安全展示的正文前缀。末尾单独的反斜杠、
不完整的 Unicode 转义等内容不属于稳定前缀，需要等待后续分片。

### 展示正文

从传输信封提取并完成 JSON 转义解码后的文本。Markdown 渲染器只消费展示正文，不感知
传输信封、JSON 转义或图表字段。
